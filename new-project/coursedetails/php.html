🐘 PHP for Backend Development

⏱️ 1 hour/day (Mon–Sat) + Sunday assessments & projects

Learn PHP from basics to building dynamic web applications, databases, sessions, and REST APIs – essential for backend developer roles.

📅 Week 1 – PHP Fundamentals & Server‑Side Logic
MondaySetup & Syntax Basics
🎯 1h: Install XAMPP/WAMP or use online PHP sandbox. Variables, data types, echo/print, comments. Embed PHP in HTML.
TuesdayOperators, Conditionals & Loops
🎯 1h: Arithmetic, comparison, logical operators. if/else, switch. for, while, foreach loops. Build a simple number guessing script.
WednesdayArrays & String Functions
🎯 1h: Indexed, associative, multidimensional arrays. Array functions: count, push, sort, merge. String functions: strlen, strpos, explode, implode.
ThursdayFunctions & Scope
🎯 1h: Define and call functions, parameters, return values. Global vs local scope. Built‑in date, math functions.
FridayForms & GET/POST Data
🎯 1h: Create HTML form, handle submission with PHP. Access $_GET and $_POST. Sanitize user input (htmlspecialchars, filter_var).
SaturdayCookies & Sessions
🎯 1h: Set/read cookies. Start a session, store user data, destroy session. Build a simple login/logout counter.
🌿 SUNDAY – Project 1: User Feedback & DashboardForms + sessions
✅ Build a small web app:
➤ A feedback form (name, rating, comment).
➤ Store submitted feedback in a session array (no database yet).
➤ Display all feedback on a separate dashboard page.
➤ Include a “reset session” button.
➤ Deliver: PHP files (index.php, dashboard.php, style.css optional).
📝 Assessment: 15 MCQs (PHP syntax, superglobals, sessions, arrays, forms).
⚡ Week 2 – MySQL Integration, Security, REST APIs
MondayMySQL Basics & phpMyAdmin
🎯 1h: Create database, tables (users, products). CRUD SQL queries (INSERT, SELECT, UPDATE, DELETE).
TuesdayPDO & MySQLi (Prepared Statements)
🎯 1h: Connect to MySQL using PDO. Write prepared statements to prevent SQL injection. Fetch data as associative array.
WednesdayBuilding a CRUD App (Part 1)
🎯 1h: Create a “products” table. Build list page (read) and add product form (create). Display products from DB.
ThursdayCRUD App (Part 2: Edit & Delete)
🎯 1h: Edit product: pre‑populate form, update query. Delete product with confirmation. Flash messages for success/error.
FridayAuthentication & Password Hashing
🎯 1h: User registration: hash password with password_hash(). Login: verify with password_verify(). Protect pages with session check.
SaturdayREST API with PHP (JSON)
🎯 1h: Create a simple API endpoint that returns JSON. Read GET parameters, handle POST to insert. Test with Postman.
🌿 SUNDAY – Final Project: Task Manager / Blog SystemFull CRUD + Auth + API
✅ Build a complete backend system (choose one):
➤ Task manager: users can register/login, create/edit/delete tasks, mark complete.
➤ Or simple blog: posts with title, content, author, timestamp.
➤ Must include: authentication, database (MySQL), CRUD for posts/tasks.
➤ Optional: create a REST endpoint to fetch posts/tasks as JSON.
➤ Deliver: All PHP source files, database SQL dump, and a README with setup steps.
📝 Final Assessment: 20 questions (PDO, SQL injection, sessions, password hashing, REST APIs, file structure).
🧭 How to succeed in 2 weeks (1h/day + Sunday projects)

✅ Daily: 20 min concept + 40 min coding (run on local server).
✅ Sunday projects take ~2–3 hours – build a portfolio for backend roles.
✅ After this curriculum, you can apply for junior PHP/backend positions and understand Laravel basics later.
📌 Recommended: PHP manual, “PHP & MySQL” by Jon Duckett, or freecodecamp.org PHP course.
