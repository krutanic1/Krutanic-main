🕷️ Web Scraping & Data Pipelines in 2 Weeks

⏱️ 1 hour/day (Mon–Sat) + Sunday assessments & projects

Learn to extract data from websites, build ETL pipelines, schedule jobs, and store data – essential for data engineering, analytics, and automation roles.

📅 Week 1 – Web Scraping (Python)
MondayHTTP, HTML, & Requests
🎯 1h: How web servers work. GET/POST requests. Use `requests` library to fetch a webpage. Inspect HTML structure (Chrome DevTools).
TuesdayBeautifulSoup Basics
🎯 1h: Parse HTML with BeautifulSoup. Find elements by tag, class, id. Extract text, attributes. Navigate the parse tree.
WednesdayExtracting Tables & Lists
🎯 1h: Scrape data from Wikipedia tables. Use `find_all('table')`, convert to pandas DataFrame. Save as CSV.
ThursdayHandling Pagination & Dynamic Content
🎯 1h: Loop through multiple pages (changing URL parameters). Identify AJAX calls (Network tab). Use `requests` with query strings.
FridayScrapy Framework Intro
🎯 1h: Install Scrapy, create a project, define a spider. Extract items and export as JSON/CSV. Scrapy shell for testing.
SaturdayRespecting robots.txt & User‑Agent
🎯 1h: Ethics and legality of scraping. Set custom headers, delay between requests. Use `time.sleep` or Scrapy `DOWNLOAD_DELAY`.
🌿 SUNDAY – Project 1: Scrape Bookstore / Job ListingsFull scraping pipeline
✅ Build a scraper for a public website (e.g., books.toscrape.com or a job board):
➤ Scrape all book titles, prices, ratings from at least 5 pages.
➤ Handle pagination automatically.
➤ Save output to CSV and JSON.
➤ Add a 1‑second delay between requests.
➤ Deliver: Python script + CSV/JSON files + a short readme.
📝 Assessment: 15 MCQs (HTTP methods, BeautifulSoup selectors, Scrapy vs requests, scraping ethics).
⚡ Week 2 – Data Pipelines (ETL, Orchestration, Storage)
MondayETL Concepts & Data Cleaning
🎯 1h: Extract, Transform, Load. Use pandas to clean scraped data: handle missing values, change data types, remove duplicates.
TuesdayStoring Data: SQLite & PostgreSQL
🎯 1h: Create tables, insert scraped data into SQLite (or PostgreSQL). Use `sqlalchemy` and `pandas.to_sql`.
WednesdayIncremental Loading & Upserts
🎯 1h: Avoid duplicates when scraping daily. Use `ON CONFLICT` or check existing records before insert.
ThursdayScheduling Pipelines (Cron / Apache Airflow basics)
🎯 1h: Schedule a Python script with cron (Linux/macOS) or Task Scheduler (Windows). Introduction to Airflow DAGs (one simple DAG).
FridayError Handling & Logging
🎯 1h: Try‑except for network failures. Retry logic. Python logging module to record pipeline runs and errors.
SaturdayWrap‑up: Full Pipeline Example
🎯 1h: Scrape → clean → store in DB → schedule daily. End‑to‑end script with functions for each stage.
🌿 SUNDAY – Final Project: Automated News/Weather PipelineScraping + ETL + Scheduling
✅ Build a complete automated data pipeline:
➤ Scrape a news site or weather forecast every hour (or daily).
➤ Clean and transform the data (extract headlines, temperature, etc.).
➤ Store in a SQLite database with timestamps.
➤ Implement incremental loading (no duplicates).
➤ Schedule the script to run automatically (cron or Task Scheduler).
➤ Deliver: Python script, database schema, scheduler configuration, and a log file showing 3 successful runs.
📝 Final Assessment: 20 questions (ETL steps, incremental loading, scheduling tools, error handling) + design a pipeline for a given scenario.
