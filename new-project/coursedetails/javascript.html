📱 JavaScript for iOS/Android (React Native)

⏱️ 1 hour/day (Mon–Sat) + Sunday assessments & projects

Build cross‑platform mobile apps for iOS and Android using JavaScript and React Native – essential for frontend and mobile development roles.

📅 Week 1 – JavaScript & React Foundations
MondayModern JavaScript (ES6+) Recap
🎯 1h: Variables (let, const), arrow functions, template literals, destructuring, spread/rest operators. Practice writing small ES6+ snippets in a REPL or browser console. (Modern JS is the foundation of React Native[reference:0].)
TuesdayAsync JS: Promises & Async/Await
🎯 1h: Fetch data from a public API using fetch(). Understand Promises, then/catch, and async/await. Mobile apps heavily rely on async operations for network calls and device APIs.[reference:1]
WednesdayReact Basics: Components & JSX
🎯 1h: Functional components, JSX syntax, props, and basic state with useState. Build a simple interactive counter component.[reference:2]
ThursdayReact Hooks: useEffect & More
🎯 1h: useEffect for side effects (data fetching, subscriptions). Understand the dependency array. Also introduce useRef and useCallback briefly.
FridayReact Native Setup & Core Components
🎯 1h: Install Node.js, watchman, and set up Expo Go on your phone. Create a new Expo project. Explore core components: View, Text, Image, ScrollView, FlatList.[reference:3]
SaturdayStyling & Flexbox in React Native
🎯 1h: Use StyleSheet.create, inline styles, Flexbox layout (justifyContent, alignItems, flexDirection). Build a simple profile card UI with image, text, and button.[reference:4]
🌿 SUNDAY – Project 1: Personal Portfolio AppBasic UI + Data Fetching
✅ Build a simple mobile portfolio app:
➤ Create a new Expo project.
➤ Design a profile screen with avatar, name, bio, and social links using Flexbox.
➤ Fetch a list of your GitHub repositories (or any public data) using fetch() and display them in a FlatList.
➤ Add a loading indicator while data loads.
➤ Deliver: Expo project folder (or GitHub repo) + a short screen recording of the app running on a simulator or physical device.
📝 Assessment: 15 MCQs (ES6+, async JS, React hooks, React Native core components, Flexbox).
⚡ Week 2 – Navigation, State Management & Native APIs
MondayReact Navigation (Stack & Tab)
🎯 1h: Install @react-navigation/native and stack/tab navigators. Create a multi‑screen app with navigation between Home, Details, and Profile screens.
TuesdayGlobal State Management (Context API)
🎯 1h: Create a simple Theme or User context using React Context API. Consume context in multiple components to manage shared state without prop drilling.
WednesdayDevice Features: Camera & Image Picker
🎯 1h: Install expo-image-picker. Implement a button that opens the device camera or gallery and displays the selected image on screen.
ThursdayLocal Storage: AsyncStorage
🎯 1h: Store and retrieve simple key‑value data (e.g., user preferences or a list of saved items) using AsyncStorage. Persist data across app restarts.
FridayForms & Input Handling
🎯 1h: Build a simple login/signup form with TextInput, validation (email, password), and form submission. Manage form state with useState.
SaturdayBuilding & Publishing (APK/IPA)
🎯 1h: Overview of generating a signed APK for Android using Expo EAS Build. Understand the process for iOS (requires Apple Developer account).[reference:5]
🌿 SUNDAY – Final Project: Note‑Taking or Task Manager AppFull CRUD with Navigation & Storage
✅ Build a complete app with the following features:
➤ User can add, edit, delete, and view notes/tasks.
➤ Use React Navigation with at least two screens (list screen + add/edit screen).
➤ Persist data locally using AsyncStorage (or SQLite if you want a challenge).
➤ Add at least one device feature (camera to add photo to note, or image picker for avatar).
➤ Implement a simple theme toggle (light/dark) using Context API.
➤ Deliver: Full Expo project, a short video demo, and a README explaining how to run the app.
📝 Final Assessment: 20 questions (navigation, Context API, device APIs, AsyncStorage, forms, build process).
🧭 How to succeed in 2 weeks (1h/day + Sunday projects)

✅ Daily: 20 min concept + 40 min coding (use Expo Go on your phone for instant preview).
✅ Sunday projects take ~2–3 hours – they become portfolio pieces for mobile developer roles.
✅ After this curriculum, you can build and deploy real cross‑platform mobile apps using JavaScript.
