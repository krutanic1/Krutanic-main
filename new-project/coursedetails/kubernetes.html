⚙️ Kubernetes in 2 Weeks

⏱️ 1 hour/day (Mon–Sat) + Sunday assessments & projects

Hands‑on, job‑ready track — no prior K8s experience needed, but basic Docker & Linux helps.

📅 Week 1 – Core Concepts
MondayArchitecture & kubectl
🎯 1h: What is Kubernetes? Control Plane vs Worker Nodes. Install Minikube & kubectl. Run kubectl get nodes.
TuesdayPods & YAML
🎯 1h: Pod as smallest unit. Write first pod.yaml, apply, inspect (kubectl get pods -o wide). Port‑forward to see app.
WednesdayDeployments & ReplicaSets
🎯 1h: Create Deployment with 2 replicas. Scale to 3. Perform rolling update (change image). Rollback.
ThursdayServices (Networking)
🎯 1h: ClusterIP, NodePort, LoadBalancer. Expose deployment via NodePort and curl from outside.
FridayNamespaces & Labels
🎯 1h: Create namespace, switch context. Use labels to filter pods (-l app=myapp). Resource quotas intro.
SaturdayRevision & mini lab
🎯 1h: Deploy nginx + custom web app. Expose via NodePort. Simulate a rolling update. Verify replicas.
🌿 SUNDAY – Assessment & ProjectNo new lessons
✅ Project 1 – Zero‑downtime web app
➤ Deploy a simple “Hello K8s” app (any image) with 3 replicas.
➤ Expose via NodePort service.
➤ Perform two rolling updates (change text/version) without downtime.
➤ Submit: YAML files + screenshot of rollout history.
📝 Assessment: Short quiz (10 questions on pods, deployments, services).
⚡ Week 2 – Production Skills
MondayConfigMap & Secrets
🎯 1h: Store config as ConfigMap, inject into pod as env. Create Secret (base64), mount as volume.
TuesdayPersistent Storage (PV/PVC)
🎯 1h: Create PersistentVolume and PersistentVolumeClaim. Deploy MySQL with PVC – data survives pod deletion.
WednesdayHealth Probes & Resources
🎯 1h: livenessProbe & readinessProbe. Set CPU/memory requests/limits. Observe pod behaviour under stress.
ThursdayIngress Controller
🎯 1h: Install NGINX Ingress (Minikube addon). Route traffic to two services using path‑based rules.
FridayHelm basics
🎯 1h: Install Helm, add repo (bitnami). Deploy a chart (e.g. WordPress), customize with values.yaml.
SaturdayRBAC + troubleshooting
🎯 1h: Create ServiceAccount, Role, RoleBinding. Practice debug: kubectl describe, logs, events.
🌿 SUNDAY – Final Project & Certification ReadinessProject + Quiz
✅ Final Project – Multi‑tier app on Kubernetes
➤ Deploy a frontend (React/Nginx) + backend (Node.js/Python) + MongoDB with persistent storage.
➤ Use ConfigMap for backend config, Secret for DB password.
➤ Expose frontend via Ingress.
➤ Implement liveness/readiness probes for backend.
➤ Deliver: All YAML manifests + a short deployment guide.
📝 Final Assessment: 20 multiple‑choice questions + 2 troubleshooting scenarios (kubectl debug).
🧭 How to succeed with 1h/day + Sunday projects

✅ Each day: 20 min video/docs + 40 min hands‑on (Minikube/Killercoda).
✅ Sunday projects take ~2–3 hours – treat them as real interview tasks.
✅ After 2 weeks you’ll be ready for CKA/CKAD prep or an entry‑level K8s role.
📌 Keep a GitHub repo with all YAML files and project outputs.
